# Order Management System (OMS)

## Project Overview

A Simple full-stack web application that tracks customer orders from estimation to job closure.

## Technology Stack

- Frontend: React.js with TypeScript
- Backend: Python with FastAPI
- Database: MySQL
- Containerization: Docker and Docker Compose
- Version Control: Git and GitHub

## Main Modules

1. Users and Login
2. Customers
3. Estimation
4. Proposal
5. Draft Order
6. Order Management
7. Projects and Work Orders
8. Execution and Invoicing
9. Job Closure
